# WEB-CMS-01 - 粉色誘惑🫦

Two independent projects:

- [`api/`](api/README.md) - NestJS + Prisma + PostgreSQL. Public read API and admin CMS API.
- [`web/`](web/README.md) - Next.js public site (English, Traditional Chinese (Taiwan), Simplified Chinese)
  and the admin panel at `/admin`.

Quick start: start PostgreSQL, then follow `api/README.md`, then `web/README.md`.
Admin panel: http://localhost:3000/admin, staging login **admin / admin123** (change before release).
